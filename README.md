# 具身智能元宇宙

> 面向具身智能（Embodied AI）与机器人领域的一站式生态服务平台，对标嘉立创模式，为二次开发公司与 OPC 一人公司提供从数据、模型、仿真到测试认证的全链路支撑。

**当前为抢先预览版，正式版即将推出，敬请期待。**

## 功能模块

| 模块 | 说明 |
|------|------|
| **数据集中心** | 本体数据集 + 火灾识别、果实识别等二次开发数据集，支持分类筛选与详情查看 |
| **模型库** | URDF 机器人模型与 AI 预训练模型资源，涵盖人形、四足、机械臂等多类本体 |
| **课程中心** | 从入门到进阶的系统化学习路径，含 B 站优质视频课程集成 |
| **云仿真平台** | 基于 Scenic 3.0 + Carla 0.9.12 + VerifAI 的仿真环境管理 |
| **研发工具** | 智能选型引导、技术方案推荐，降低开发门槛 |
| **云监控平台** | 实时设备状态监控、数据可视化看板（ECharts） |
| **二次开发** | SDK 下载、API 文档、代码示例、开发者工具链 |
| **标准认证中心** | 覆盖 86 项国家标准，横跨电磁兼容、功能安全、机械安全等 13 大类 |
| **供应链商城** | 真实产品与图片，支持分类浏览、购物车与订单管理 |
| **众创社区** | 资讯动态、技术讨论、项目协作 |

## 标准认证体系

平台集成 13 大类共 86 项国家标准，为机器人产品开发与检测提供权威依据：

- 电磁兼容（14 项） · 电气安全（6 项） · 各领域性能测试（27 项）
- 功能安全（13 项） · 机械安全（8 项） · 信息安全（2 项）
- 协同安全（4 项） · 协议兼容（4 项） · 算法可信（3 项）
- 预期功能安全（2 项） · 可靠性（1 项） · 能效（1 项） · 碳足迹（1 项）

## 技术架构

- **前端框架**：Vue 3（CDN 全局构建）
- **UI 组件库**：Element Plus
- **数据可视化**：ECharts 5
- **构建方式**：零构建（Vanilla JS），浏览器直接加载

## 目标用户

- **二次开发公司**：需要数据集、模型、仿真环境和标准认证的机器人企业
- **OPC 一人公司**：独立开发者，需要一站式工具链降低研发门槛
